[太初易筮](https://github.com/zhao922-bot/taichu-yishi) 是一个基于 Flutter 的《高岛易断》传统占筮应用。它把起筮过程拆成清楚的步骤，卦辞、爻辞和逐条《占断》随应用本地打包，不需要联网请求。

这是我在传统文化方向上的一次软件尝试：把原本需要查书、记步骤的过程整理成可以在本机完成、保存和恢复的工具。它不试图替代对经典文本的阅读，主要用于学习传统筮法和个人省思。

公开 GitHub Release 从 **2026 年 8 月 20 日** 的 v1.0.1 开始。截至 2026-10-21，最新正式下载仍是 **v1.1.0**，`main` 源码版本为 **v1.2.0+4**，并在 10 月 18 日继续补充修复。两者需要分开看：源码更新不代表对应安装包已经发布。

## v1.0.1 · 2026-08-20

v1.0.1 是太初易筮的首次公开版本，核心是把不同的传统起筮方法整理成几条可以逐步完成的流程：

- **周易传统筮法**：使用 49 策逐爻完成十八变，可以出现多爻动。
- **49 签略筮法**：根据性别显示左手或右手的分签顺序，三次分签确定上卦、下卦和动爻。
- **八卦签 + 六爻签**：依次抽取上卦、下卦和动爻。
- **64 卦签 + 六爻签**：先抽取本卦，再抽取动爻。
- **384 爻签**：一次抽取同时确定本卦和动爻。

卦辞、爻辞和逐条《占断》来自随项目打包的 EPUB 提取数据。起筮过程、分签和结果计算都在本机完成，不需要向服务器发送问题文本或卦象数据。

## 使用体验

界面提供三种样式：阴（夜色漆金）、阳（宣纸日光）和跟随系统。尚未完成的起筮会保存到本机，下次可以继续；如果不想保留，也可以主动放弃本次起筮。

v1.0.1 当时提供 Android APK、AAB 和 Windows x64 便携版。最新 v1.1.0 Release 提供 Android APK 与 AAB，未附 Windows 包；Windows 用户可查看历史包或按源码说明构建，不能把旧包当作最新版本。

## v1.1.0 · 2026-10-05

- 包名更正为 `taichu_yishi`，代码拆分为入口、筮法引擎、界面与样式模块。
- 起筮完成后的边界状态与非法分堆改为安全提示。
- “亲自分堆 / 自动分堆”选择在多步骤之间保持。
- 结果页使用上卦在上、下卦在下的传统竖排卦符。
- 增加 GitHub Actions 静态分析与测试，补齐 iOS / macOS 工程支持。

本版更换了 Android 发布签名。发布说明要求 v1.0.1 用户卸载后重装，无法直接覆盖；需要保留的本地内容应在卸载前处理。

## v1.2.0 源码 · 2026-10-09

传统筮法的自动分签改用“余数均匀”随机模型，更贴近传统手分的概率特性。经文按通行本校正了夬卦辞去“吉”、困九五“劓刖”、艮卦辞“艮其背”、既济六四“有衣袽”四处文字。

同时修复略筮法自动模式换步后分堆固定、空右堆归余、第二变剩余变数文案、异常存档恢复、持久化串行化、启动偏好降级和分堆手势误触。问题文本、进度与界面偏好仍在本地保存。

以上来自 [main 分支 README](https://github.com/zhao922-bot/taichu-yishi/blob/main/README.md)。截至本次更新，公开 Release 列表中尚无 v1.2.0，因此这里标记为源码进展。

## 10 月 18 日：源码继续补齐边界体验

本轮没有增加新的筮法，而是修复四类使用细节：64 卦签流程的说明改为需要时生成；本地偏好类型异常时可以恢复；筮法说明支持滚动；大字号下分堆数量可以换行，减少横屏、小屏或放大字体时的内容遮挡。

对应[源码提交](https://github.com/zhao922-bot/taichu-yishi/commit/3b75d69744650b5072b7e52af6d923419bf8edf4)新增 25 项回归测试，记录了总计 51 项测试通过、静态分析通过，以及 Windows Release 和 Android Debug 构建成功。Android Debug 构建不等于正式签名安装包；截至本文更新，下载按钮仍指向已公开的 v1.1.0。
