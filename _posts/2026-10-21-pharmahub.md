**药枢 PharmaHub** 是我新增的中文药物机制学习项目，面向药学、生物制药专业的学习者，以及想重新梳理药理知识的人。它把机制卡片、机制图、同类药对比和复习记录放在一起，让阅读、理解、测验与回顾可以接着进行。

截至 2026-10-21，项目包含 **123 张药物卡片、36 组同类药对比**，云端版已经上线，GitHub 源码仓库也已公开。目前没有单独的 GitHub Release 安装包，日常使用直接打开在线网址即可。

[打开药枢在线版](https://pharmahub.ampleox17.chatgpt.site){: .button .button-primary target="_blank" rel="noopener noreferrer" }

[查看 GitHub 源码](https://github.com/zhao922-bot/pharmahub){: .button .button-secondary target="_blank" rel="noopener noreferrer" }

在线版需要使用自己的 ChatGPT 账号登录，手机和电脑都可以通过浏览器访问，不需要启动原来的电脑或连接同一个 Wi-Fi。内容仅供药学学习参考，不用于诊断、处方或个体化用药决策。

## 从机制卡片到主动复习

卡片整理药物的作用靶点、机制、用途、相关风险、记忆要点与参考资料，并配有机制图。图示帮助读者跟踪药物、靶点和后续变化之间的关系；同类药对比则把容易混淆的知识点放在一起查看。

读完之后，可以用普通测验或同类药对比测验检验理解，再查看解析。答错的题目进入错题本，方便以后重练。药枢同时提供掌握程度自评与基于 SM-2 的间隔复习，用下次复习日期、连续学习天数和热力图呈现学习进展。

收藏、全文搜索、分类筛选与 CSV / JSON 导出也已加入，既可以按计划复习，也可以临时查找某张卡片或某组对比。当前内容规模是本次更新时的记录，后续以站内内容和仓库说明为准。

## 云端版：同一账号跨设备继续

云端版使用 ChatGPT 登录身份保存个人记录。复习进度、收藏、测验作答和错题都按账号隔离，新账号从空白记录开始；在手机和电脑上登录同一账号，可以读取云端已保存的进度。药物卡片、机制图、对比内容与参考资料则由所有学习者共用。

每天的统计与复习计划统一按 **UTC+8** 计算。在线版需要联网，个人页面与学习记录不进入离线页面缓存；导出功能只导出当前登录账号的记录。

开始使用可以按下面的顺序：

1. 打开在线网址，使用自己的 ChatGPT 账号登录。
2. 找到一张卡片，阅读机制图与参考资料，完成掌握程度自评或加入收藏。
3. 参加普通测验或同类药对比测验，查看解析，再回到错题本与复习计划。
4. 换设备后登录同一账号，刷新页面读取已保存的记录；需要留存时导出学习数据。

## 本地版与云端版有什么区别

项目保留两个分支，各自对应不同的使用方式：

| 项目 | main 本地版 | online 云端版 |
| --- | --- | --- |
| 运行方式 | 在自己的电脑启动 Next.js / Node.js 服务 | 直接访问已上线的网站 |
| 数据保存 | 运行服务的电脑上的 SQLite | 云端 Cloudflare D1 |
| 账号 | 没有 ChatGPT 登录与按账号隔离 | ChatGPT 登录，个人记录按账号隔离 |
| 多设备 | 访问同一本地服务的设备共用记录 | 同一账号在不同设备继续学习 |
| 访问条件 | 本地服务需要保持运行 | 需要联网，无需原电脑开机 |

两套数据库相互独立。原本地历史**不会自动上传、迁移或与云端合并**，原来的本地项目与数据仍然保留。源码公开也不代表个人云端学习记录被公开，这些记录不包含在 GitHub 仓库中。

## 实现与验证

本地版使用 Next.js、React 与 SQLite；云端版在 `online` 分支中采用 Vinext、React、Cloudflare Workers 和 D1，通过 Sites 托管。卡片内容与机制图结构分开组织，机制图由结构数据生成 SVG，方便维护共同的图示规则。

根据[云端版项目说明](https://github.com/zhao922-bot/pharmahub/blob/online/README.md)，上线时完成了 252 项测试及 66 项浏览器检查，覆盖手机与桌面布局、跨会话读取、测验保存、解析、错题与导出。开放访问时另复核了账号隔离、并发写入和日期边界等数据检查。这些是程序与交互的验证结果，不等同于药物知识已经通过独立专业审定。

## 学习用途与数据边界

卡片和机制图包含教学简化，参考资料与核对日期用于帮助追溯内容，不能保证覆盖所有制剂、地区或用药情境。同类药对比也不意味着可以自行互换药物。实际用药应依据适用的产品说明书，并咨询医生或药师。

个人记录通过应用层账号权限隔离，云端服务仍有故障、配置错误和数据丢失等风险。目前没有一键删除全部云端记录的入口，退出登录或清理浏览器缓存也不会删除全部云端数据。需要保存的学习记录可以自行导出，请勿把药枢作为患者身份、病历或处方的存储工具。
